Using the Terminal, for beginners

Some fixes ask you to type a command. The Terminal (Command Prompt on Windows) is just a window where you type an instruction and press Enter. This page shows how, on every computer.

#What it is

A plain window with a blinking cursor. You type (or paste) one line, press Enter (Mac: Return), and the computer does it and prints the result. You cannot break anything by opening it, and closing the window is always safe.

#Opening it on Windows

  1. Press Windows + RA small Run box opens at the bottom left.
  2. Type cmd and press EnterA black Command Prompt window opens.

To paste a command: Ctrl + V, or right-click inside the window. Then press Enter.

Example: to see your Node.js version, type node -v and press Enter. It prints something like v20.19.0. If it prints not recognized, Node.js is not installed for the whole PC, which is fine: the app keeps its own copy.

#Opening it on a Mac

  1. Press Cmd + SpaceThe Spotlight search bar opens in the middle of the screen.
  2. Type Terminal and press ReturnA white or black Terminal window opens.

Or: Finder → Applications → Utilities → Terminal.

To paste a command: Cmd + V, then Return.

#Opening it on Linux

Press Ctrl + Alt + T, or search for Terminal in your apps. To paste: Ctrl + Shift + V, then Enter.

#Four things worth knowing

  • Drag a file in to type its location. Instead of typing a long folder path, drag the file from Finder or File Explorer into the Terminal window; its full path appears, ready to use.
  • Passwords are invisible. When it asks for your password, nothing appears as you type, not even dots. Type it anyway and press Enter.
  • Names with spaces need quotes. "Reazix Billing - MAC.command". Dragging the file in adds what is needed for you.
  • To stop a command that keeps running, press Ctrl + C.

#Example: fixing the Mac launcher

If a Mac says the launcher could not be executed because you do not have appropriate access privileges:

  1. Open TerminalCmd + Space, type Terminal, Return.
  2. Type the start of the commandType chmod +x and then one space. Do not press Return yet.
  3. Drag the launcher inDrag Reazix Billing - MAC from your Reazix-Billing folder into the Terminal window. The line now ends with its location.
  4. Press ReturnNothing is printed: that means it worked. Close Terminal and open the launcher again (Control-click → Open).
